    Install gitleaks if not present: `go install github.com/gitleaks/gitleaks/v8@latest` or download binary.
    If gitleaks is not available, use `trufflehog git file://. --only-verified` as fallback.
    If neither tool is installable in the sandbox, perform a manual grep-based scan:
    ```
    grep -rn "AKIA\|sk-\|ghp_\|ghs_\|glpat-\|xoxb-\|xoxp-\|-----BEGIN.*PRIVATE KEY" --include="*.py" --include="*.ts" --include="*.tsx" --include="*.js" --include="*.json" --include="*.yml" --include="*.yaml" --include="*.toml" --include="*.env*" --include="*.sh" . | grep -v node_modules | grep -v .git/
    ```
    Also scan git history for common secret patterns:
    ```
    git log --all -p -- '*.env' '*.env.*' 2>/dev/null | head -200
    git log --all --diff-filter=D -- '*.env' '*.key' '*.pem' 2>/dev/null
    ```
    Record all findings. Zero tolerance — any real secret must be flagged as a blocker.

    **B. PII / internal-reference scrub (D-28c):**
    Search for:
    (i) Real email addresses (not @example.com, not @test.com, not the public contact): `grep -rn "@" --include="*.py" --include="*.ts" --include="*.tsx" --include="*.json" --include="*.yml" . | grep -v node_modules | grep -v .git/ | grep -v "@example\|@test\|@localhost\|@types\|@radix\|@tanstack\|@hookform\|@fontsource\|@babel\|@jridgewell\|@nodelib\|@alloc\|@wavesurfer\|@vitejs\|import\|from\|require"`
    (ii) Internal Slack/Notion/Jira/Confluence URLs: `grep -rn "slack.com\|notion.so\|atlassian.net\|jira\.\|confluence\." --include="*.py" --include="*.md" --include="*.ts" . | grep -v node_modules`
    (iii) Hardcoded staging/dev URLs (not localhost): `grep -rn "staging\.\|dev\.\|internal\." --include="*.py" --include="*.ts" --include="*.yml" . | grep -v node_modules | grep -v .git/ | grep -v "# "`
    (iv) Test fixtures with real PII: `grep -rn "SSN\|social security\|555-\|123-45-6789" --include="*.py" --include="*.json" . | grep -v node_modules`
    Record all findings with file paths and line numbers.
