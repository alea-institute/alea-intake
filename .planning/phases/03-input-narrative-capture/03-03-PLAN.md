    **1. Create backend/app/services/document/extractors/pdf_extractor.py**:
    - `async def extract_pdf(file_path: Path) -> tuple[str, list[dict]]`:
      - Uses `asyncio.get_event_loop().run_in_executor(None, _extract_sync)`.
      - Inner `_extract_sync()`:
        - `import pymupdf` (the PyMuPDF import name).
        - Opens doc = pymupdf.open(str(file_path)).
        - Iterates pages. For each page: gets text via page.get_text(), gets structured blocks via page.get_text("dict")["blocks"].
        - For each text block (type==0), iterates lines/spans. Classifies element_type based on font size: >= 16pt = "heading", else "paragraph". Stores {text, element_type, page, bbox, font_size}.
        - Collects page_texts joined by "\n\n".
        - doc.close().
        - Returns (full_text, elements).

    **2. Create backend/app/services/document/extractors/docx_extractor.py**:
    - `async def extract_docx(file_path: Path) -> tuple[str, list[dict]]`:
      - Uses run_in_executor.
      - Inner `_extract_sync()`:
        - `from docx import Document` (python-docx).
        - Opens Document(str(file_path)).
        - Iterates paragraphs. Classifies: p.style.name starting with "Heading" -> element_type="heading" with heading level. Otherwise "paragraph".
        - Iterates tables. For each table, joins cell text into tab-delimited rows. element_type="table".
        - Returns (full_text joined by "\n\n", elements).

    **3. Create backend/app/services/document/extractors/ocr_extractor.py**:
