<objective>
Build the document processing service with format-specific extractors (PDF via PyMuPDF, DOCX via python-docx, images via pytesseract) and wire document upload into the intake router and message pipeline.

Purpose: Enables document input modality end-to-end. Consumers can upload legal documents via a REST endpoint, the system extracts structured text, stores it as a Message with modality="document", and normalizes it into the same stream as text and voice messages. Per CONTEXT.md locked decision: "seamless multi-modal mixing within a session: any message can be text, voice recording, or document upload -- all normalized into the same stream."

Output: Working document service with 3 extractors, document upload REST endpoint in intake router, message_pipeline document modality wiring, test fixtures with sample files.
</objective>

      - Uses `asyncio.get_event_loop().run_in_executor(None, _extract_sync)`.
      - Inner `_extract_sync()`:
        - `import pymupdf` (the PyMuPDF import name).
        - Opens doc = pymupdf.open(str(file_path)).
        - Iterates pages. For each page: gets text via page.get_text(), gets structured blocks via page.get_text("dict")["blocks"].
        - For each text block (type==0), iterates lines/spans. Classifies element_type based on font size: >= 16pt = "heading", else "paragraph". Stores {text, element_type, page, bbox, font_size}.
        - Collects page_texts joined by "\n\n".
        - doc.close().
        - Returns (full_text, elements).
