    **1. Create backend/app/services/extraction/schemas.py** with Pydantic models for LLM structured output:
    ```python
    from pydantic import BaseModel, Field

    class ExtractedEntitySchema(BaseModel):
        """A single extracted entity from narrative text."""
        entity_type: str  # person, date, location, amount, organization,
                          # party_relationship, legal_event, document_reference,
                          # time_period, claimed_damages
        value: str
        confidence: float = Field(ge=0.0, le=1.0)
        source_start: int  # char offset in normalized text
        source_end: int

    class ExtractedFactSchema(BaseModel):
        """An atomic factual assertion decomposed from narrative."""
        assertion: str  # Natural language statement of the fact
        fact_type: str  # event, relationship, amount, date, condition, sequence
        entities: list[ExtractedEntitySchema] = Field(default_factory=list)
        confidence: float = Field(ge=0.0, le=1.0)
        source_start: int
        source_end: int

    class ExtractionResultSchema(BaseModel):
        """Complete extraction from a single message."""
        facts: list[ExtractedFactSchema] = Field(default_factory=list)
        entities: list[ExtractedEntitySchema] = Field(default_factory=list)
    ```

    **2. Create backend/app/services/extraction/fact_extraction.py**:
    - Module-level `EXTRACTION_SYSTEM_PROMPT` constant (use the prompt from 03-RESEARCH.md Code Examples section -- the one that lists all entity types: person, date, location, amount, organization, party_relationship, legal_event, document_reference, time_period, claimed_damages -- and the 5 rules about only extracting stated facts, requiring source spans, confidence scoring, contradiction handling, and atomic decomposition).

    - `class FactExtractionService`:
      - `__init__(self, llm_service: LLMService, db_session: AsyncSession)`: Stores references.
      - `async def extract_facts(self, text: str, session_facts: list[dict] | None = None) -> ExtractionResultSchema`:
        - Builds messages list: system prompt = EXTRACTION_SYSTEM_PROMPT, user message = text (with context of session_facts if provided for contradiction detection).
        - Calls LLMService to get structured JSON output. The call should request JSON output matching ExtractionResultSchema.
        - Parses response into ExtractionResultSchema using Pydantic validation. If parsing fails, returns ExtractionResultSchema(facts=[], entities=[]).
        - Validates source spans: for each fact, checks that source_start and source_end are within bounds of the text. Drops facts with invalid spans.
        - Returns validated ExtractionResultSchema.

      - `async def extract_and_persist(self, normalized: NormalizedContent, intake_id: int, message_id: int, party_id: int | None = None, session_facts: list[dict] | None = None) -> list[ExtractedFact]`:
        - Calls self.extract_facts(normalized.text, session_facts).
        - For each fact in result.facts:
          - Creates ExtractedFact record: intake_id, message_id, party_id, assertion_text=fact.assertion, fact_type=fact.fact_type, entity_type=fact.entities[0].entity_type if entities else None, confidence=fact.confidence, is_active=True, visibility from settings (get_settings().intake_fact_visibility), metadata_json={"entities": [e.model_dump() for e in fact.entities]}.
          - Creates FactSourceSpan record: fact_id, message_id, start_char=fact.source_start, end_char=fact.source_end. If source_type is "voice", also sets timestamp fields from kwargs. If "document", sets page_number from source spans.
          - Handles same-party supersession: if session_facts contains a fact from the same party with overlapping entity values (e.g., same entity_type + similar value), marks the old fact's is_active=False and sets superseded_by_id to the new fact's id.
        - Commits and returns list of created ExtractedFact records.

      - `async def get_session_facts(self, intake_id: int) -> list[dict]`:
        - SELECT * FROM extracted_facts WHERE intake_id=X AND is_active=True ORDER BY created_at.
        - Returns as list of dicts with assertion_text, fact_type, entity_type, confidence, party_id.
