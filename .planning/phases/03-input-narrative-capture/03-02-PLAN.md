    - `class ASRProviderBase(ABC)`:
      - `@abstractmethod async def transcribe(self, audio_bytes: bytes, format: str, **kwargs) -> TranscriptionResult`
      - `async def transcribe_streaming(self, audio_stream: AsyncIterator[bytes], **kwargs) -> AsyncIterator[str]`: raises NotImplementedError.

    **2. Create backend/app/services/asr/providers/whisper_provider.py**:
    - `class WhisperProvider(ASRProviderBase)`:
      - `__init__(self, endpoint: str = "http://localhost:8790", **kwargs)`: Stores endpoint. Accepts and ignores org_config kwarg for consistency.
      - `async def transcribe(self, audio_bytes, format, **kwargs) -> TranscriptionResult`:
        - Uses `httpx.AsyncClient` with timeout=120.0.
        - POSTs to `{endpoint}/transcribe` with files={"audio": ("audio.{format}", audio_bytes)} and data={"language": kwargs.get("language", "en")}.
        - Parses JSON response into TranscriptionResult(text=data["text"], segments=data.get("segments", []), language=data.get("language"), confidence=data.get("confidence")).
        - Raises `httpx.HTTPStatusError` on non-2xx.

    **3. Create backend/app/services/asr/providers/deepgram_provider.py**:
    - `class DeepgramProvider(ASRProviderBase)`:
      - `__init__(self, api_key: str | None = None, **kwargs)`: Stores API key from param or org_config.
      - `async def transcribe(self, audio_bytes, format, **kwargs) -> TranscriptionResult`:
        - Tries `from deepgram import DeepgramClient, PrerecordedOptions` (ImportError if not installed).
        - Creates DeepgramClient with api_key. Calls listen.asyncrest.v("1").transcribe_file with source={"buffer": audio_bytes, "mimetype": f"audio/{format}"} and options=PrerecordedOptions(model="nova-2", smart_format=True, diarize=kwargs.get("diarize", False)).
        - Parses response into TranscriptionResult.
      - `@property supports_streaming` returns True.
      - `@property supports_diarization` returns True.

    **4. Create backend/app/services/asr/providers/assemblyai_provider.py**:
    - `class AssemblyAIProvider(ASRProviderBase)`:
      - `__init__(self, api_key: str | None = None, **kwargs)`: Stores API key from param or org_config.
      - `async def transcribe(self, audio_bytes, format, **kwargs) -> TranscriptionResult`:
        - Tries `import assemblyai as aai` (ImportError if not installed).
        - Sets aai.settings.api_key. Creates Transcriber, transcribes from bytes.
        - Parses response into TranscriptionResult.
      - `@property supports_diarization` returns True.

    **5. Create backend/app/services/asr/providers/__init__.py** exporting all providers and TranscriptionResult.

    - `async def convert_audio_format(audio_bytes: bytes, input_format: str, output_format: str = "wav") -> bytes`:
      - Uses asyncio.get_event_loop().run_in_executor with pydub: `AudioSegment.from_file(BytesIO(audio_bytes), format=input_format)`, export to output_format (wav: parameters=["-ac", "1", "-ar", "16000"] for mono 16kHz).

      - `async def transcribe(self, audio_bytes: bytes, format: str, **kwargs) -> TranscriptionResult`: Converts format if needed (webm/opus/ogg -> wav for providers that don't accept them natively). Delegates to self.provider.transcribe.
