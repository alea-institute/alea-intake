    - chunk(text, max_tokens=500, overlap=50) -> list[ChunkResult]: Split text by paragraph boundaries first (\n\n), then by sentence boundaries if paragraphs exceed max_tokens. Respect headings: Markdown headings (# ## ###) and uppercase-line headings stay with their following content. Each ChunkResult contains: content (str), heading (str | None), chunk_index (int), token_count (int), start_offset (int), end_offset (int). Overlap: last overlap tokens of chunk N repeated at start of chunk N+1. Use simple whitespace tokenization for token counting (accurate enough for chunking).

    Per D-13, create FolioTagger:
    - __init__(concept_resolver: ConceptResolver | None): Inject resolver.
    - async tag_chunk(chunk: ChunkResult) -> list[TagResult]: If chunk.heading is not None, resolve heading text via ConceptResolver. Return list of TagResult(iri=str, label=str, confidence=float). If no heading or no resolver, return empty list.
    - async tag_chunks(chunks: list[ChunkResult]) -> list[list[TagResult]]: Batch tag all chunks.

    - __init__(embedding_service: EmbeddingService, concept_resolver: ConceptResolver | None, db_session: AsyncSession): Inject deps.
    - async search(query: str, org_id: int, top_k: int = 10, folio_iris: list[str] | None = None) -> list[KBSearchResult]: (1) Embed query via EmbeddingService. (2) Search per-org vector index (top_k=20 for oversampling). (3) If folio_iris provided, boost chunks whose folio_iris_json overlaps (multiply score by 1.5 for overlapping IRIs). (4) Sort by boosted score, return top_k. Per Pitfall 3: FAISS indices are per-org (separate files, loaded on demand). For pgvector: filter by org_id.
    - KBSearchResult: chunk_content (str), document_title (str), document_id (int), score (float), folio_iris (list[str]).

    - async get_insights(folio_iri: str, top_k: int = 5) -> list[KBSearchResult]: Query KB with FOLIO IRI filter + source_type="insight".
    - async add_insight(folio_iri: str, content: str, source: str = "llm") -> int: Create KBDocument(source_type="insight"), chunk, tag, embed, return document_id.
