    **useGraphData.ts** -- Pure transformation hook:
    - Takes VisualizationData + filter state from store
    - Creates GraphNode for each fact (type='fact', label=assertion_text truncated to 40 chars, confidence from fact)
    - Creates GraphNode for each claim (type='claim', label=claim_name)
    - Creates GraphNode for each element across all claims (type='element', label=element_name)
    - Creates GraphNode for each gap (type='gap', label=description truncated to 40 chars)
    - Creates GraphLink for each mapping: fact->claim link, and if element_id exists, fact->element link
    - Creates links between claims and their elements (structural edges)
    - Applies filter state: nodes not matching jurisdiction/claim/confidence filters get `ghosted: true` property rather than being removed per D-04
    - Returns { nodes: GraphNode[], links: GraphLink[], ghostedNodeIds: Set<string> }

    **useForceSimulation.ts** -- D3-force simulation hook per D-01:
    - Takes nodes: GraphNode[], links: GraphLink[], width: number, height: number
    - Creates d3.forceSimulation with:
      - forceLink().id(d => d.id).distance(80) for relationship edges
      - forceManyBody().strength(-200) for node repulsion
      - forceCenter(width/2, height/2) for centering
      - forceCollide(d => 10 + d.confidence * 15) for size-aware collision
    - CRITICAL: Clone node/link arrays before passing to simulation (Pitfall 1 -- D3 mutates input)
    - Simulation ref stored in useRef, tick callback calls setState with [...simNodes] spread
    - Cleanup: simulation.stop() on unmount (Pitfall 2)
    - Expose simulation ref for drag reheat integration
    - Returns { positions: GraphNode[], simulation: RefObject }
    - IMPORTANT: Do NOT put tick-by-tick positions in Zustand -- use local useState per anti-pattern warning in research
  </action>
