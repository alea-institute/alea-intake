    **useExport.ts** -- per D-17:

    Returns an object with three export functions:

    **exportGraph(elementRef: HTMLElement, format: 'svg' | 'png'):**
    - Uses html-to-image: toSvg(el, { backgroundColor: 'white' }) or toPng(el, { backgroundColor: 'white' })
    - Wait for requestAnimationFrame before capture (Pitfall 6 -- ensure React has flushed state)
    - For Canvas mode: use canvas.toDataURL('image/png') directly (html-to-image doesn't work on Canvas)
    - Trigger download via creating <a> element with download attribute
    - Filename: `analysis-graph-{intakeId}.{svg|png}`

    **exportMatrixCSV(data: VisualizationData, matrixData: MatrixData):**
    - Build CSV header row: "Fact", then element names (grouped by claim)
    - Build data rows: fact assertion_text, then confidence values (or empty for gaps)
    - CSV cells quoted to handle commas in text
    - Trigger download via Blob with text/csv mime type
    - Filename: `analysis-matrix-{intakeId}.csv`
    - Also support exportMatrixPNG using toPng on the matrix container ref

    **exportNarrativePDF(narrativeData: NarrativeData):**
    - Create jsPDF instance
    - Set font size 12, render title "Analysis Narrative" at top
    - For each message: render sender label as bold header, then text
    - Annotated segments: render text with footnote markers (superscript numbers)
    - At bottom: footnotes section listing each annotation's claim names and confidence
    - Page breaks via doc.addPage() when y exceeds margin
    - Trigger download: doc.save(`analysis-narrative-{intakeId}.pdf`)
    - Note: This is an MVP plain-text-with-footnotes PDF per research recommendation (not pixel-perfect highlight reproduction). Comment noting server-side WeasyPrint could provide higher fidelity.

    All export functions respect current filter state from store -- only exported items that pass current filters.

    Helper: `downloadDataUrl(dataUrl: string, filename: string)` and `downloadBlob(blob: Blob, filename: string)` shared utilities.
  </action>
