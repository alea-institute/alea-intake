  <action>
    **useMatrixData.ts** -- Transform VisualizationData into matrix structure:

    Input: VisualizationData from API, filter state from store

    Output interface:
    ```typescript
    interface MatrixData {
      rows: MatrixRow[]        // facts (filtered + sorted)
      columnGroups: ClaimGroup[] // claims with element columns
      getCellData: (factId: number, elementId: number) => MatrixCell | null
      totalColumns: number
    }
    interface MatrixRow {
      factId: number
      label: string           // assertion_text
      confidence: number
    }
    interface ClaimGroup {
      claimId: number
      claimName: string
      jurisdiction: string | null
      collapsed: boolean
      columns: ElementColumn[]
    }
    interface ElementColumn {
      elementId: number
      elementName: string
      isGap: boolean          // true if no fact maps to this element
      isSatisfied: boolean
    }
    ```

    Processing:
    1. Build column groups from claims[].elements[], one group per claim
    2. Mark element columns as isGap when no mapping exists for that element_id across any fact
    3. Build cell lookup Map<`${factId}-${elementId}`, MatrixCell> from mappings array
    4. Apply filters: jurisdiction filter hides claims (and their elements) not matching, claim filter hides unselected claims, confidence threshold hides facts below threshold
    5. Apply sort: 'confidence' sorts facts by their highest mapping confidence, 'source_order' keeps insertion order
    6. Memoize with useMemo keyed on data + filter state

    Gap columns should be flagged with a warning indicator in the header (isGap=true flag consumed by MatrixHeader).
  </action>
