    1. Create backend/app/deployment/persistence.py per D-07, D-08:
       - PersistenceManager class:
         - get_mode(org: Organization) -> PersistenceMode: reads org.settings["persistence_mode"], defaults to PERSISTENT
         - async handle_session_complete(intake_id: int, org: Organization, session: AsyncSession) -> None:
           - EPHEMERAL: Check session status is terminal (completed/abandoned) -- Pitfall 5. If terminal, schedule deletion via _schedule_deletion. If active, do nothing (session still in progress).
           - PERSISTENT: No action (data retained until right-to-delete)
           - CMS_INTEGRATED: If org has CMS configured, enqueue CMS sync. Local retention per org.settings["cms_retention_hours"] or forever.
         - async _schedule_deletion(intake_id: int, ttl_hours: int, org: Organization, session: AsyncSession) -> None:
           - TTL starts from session completion timestamp, NOT creation (Pitfall 5)
           - Uses asyncio.create_task with asyncio.sleep(ttl_hours * 3600) then calls _execute_ephemeral_deletion
         - async _execute_ephemeral_deletion(intake_id: int, org: Organization, session: AsyncSession) -> None:
           - Re-check session is still terminal (guard against race)
           - Delete: messages, extracted facts, fact source spans, analysis runs/iterations/stages/claims/elements/mappings/gaps/questions, documents, audio recordings, output documents, intake session, consumer PII
           - KEEP: anonymized audit trail (set actor_id=None per DeletionService pattern), screening trigger counts (D-08)
           - Uses existing DeletionService cascade pattern where applicable
         - _pending_deletions: dict[int, asyncio.Task] to track scheduled deletions (cancel on session resume)
