<objective>
Build bidirectional CMS sync connectors for Clio, MyCase, and LegalServer using the adapter ABC pattern. Each adapter handles its CMS-specific auth (OAuth2 or API key), field mapping, and webhook processing. A background sync queue decouples CMS operations from the intake flow.

Purpose: Legal organizations need intake data to flow into their existing case management systems without manual re-entry.
Output: Three CMS adapters, sync infrastructure, and admin API.
</objective>
