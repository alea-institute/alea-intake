    **backend/app/services/auth_service.py:**
    - `class AuthService`:
      - `__init__(self, session: AsyncSession)`
      - `async def register(self, email: str, password: str, full_name: str, org_id: int, role: str = "consumer") -> tuple[User, str, str]`:
        - Check if email already exists in this tenant (raise 409 if so)
        - Hash password with `hash_password()`
        - Create User with `hashed_password=hashed`, `full_name=full_name.encode("utf-8")` (plain bytes for now -- encryption added in Plan 03)
        - Generate token_family UUID with `uuid.uuid4().hex`
        - Create access token and refresh token
        - Store RefreshToken record (hash the refresh token before storage with `hashlib.sha256`)
        - Return `(user, access_token, refresh_token)`
      - `async def login(self, email: str, password: str) -> tuple[User, str, str]`:
        - Look up user by email
        - If not found or `verify_password` fails: raise HTTPException 401 with `detail="Invalid email or password"`
        - Generate new token family, create tokens, store refresh token
        - Return `(user, access_token, refresh_token)`
      - `async def refresh_tokens(self, refresh_token_str: str) -> tuple[str, str]`:
        - Decode the refresh token JWT
        - Hash the token string, look up RefreshToken by hash
        - If not found or `is_revoked=True`: revoke ALL tokens in the family (reuse attack), raise 401
        - Mark current refresh token as revoked
        - Generate new refresh token in same family, create new access token
        - Store new RefreshToken record
        - Return `(new_access_token, new_refresh_token)`
      - `async def logout(self, user_id: int, token_family: str) -> None`:
        - Revoke all RefreshToken records for this user in this family
