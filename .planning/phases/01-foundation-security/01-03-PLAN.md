  <action>
    **backend/app/core/encryption.py:**
    - Import `os` from stdlib, `AESGCM` from `cryptography.hazmat.primitives.ciphers.aead`
    - `class EnvelopeEncryption`:
      - `__init__(self, kek: bytes)`: validate kek is exactly 32 bytes, store as `self.kek`
      - `def generate_dek(self) -> bytes`: return `AESGCM.generate_key(bit_length=256)` -- 32 bytes
      - `def wrap_dek(self, dek: bytes) -> bytes`:
        - `nonce = os.urandom(12)` -- 12-byte nonce for AES-GCM
        - `aesgcm = AESGCM(self.kek)`
        - `encrypted = aesgcm.encrypt(nonce, dek, None)`
        - return `nonce + encrypted` -- prepend nonce (first 12 bytes) for unwrapping
      - `def unwrap_dek(self, wrapped_dek: bytes) -> bytes`:
        - `nonce = wrapped_dek[:12]`
        - `encrypted = wrapped_dek[12:]`
        - `aesgcm = AESGCM(self.kek)`
        - return `aesgcm.decrypt(nonce, encrypted, None)`
      - `def encrypt_field(self, dek: bytes, plaintext: str) -> bytes`:
        - `nonce = os.urandom(12)`
        - `aesgcm = AESGCM(dek)`
        - `encrypted = aesgcm.encrypt(nonce, plaintext.encode("utf-8"), None)`
        - return `nonce + encrypted`
      - `def decrypt_field(self, dek: bytes, ciphertext: bytes) -> str`:
        - `nonce = ciphertext[:12]`
        - `encrypted = ciphertext[12:]`
        - `aesgcm = AESGCM(dek)`
        - return `aesgcm.decrypt(nonce, encrypted, None).decode("utf-8")`

    **CRITICAL: Do NOT import Fernet. Use only AESGCM for AES-256 compliance. Fernet is AES-128-CBC.**

    **backend/app/core/key_management.py:**
    - `class KeyManager`:
      - `__init__(self, master_key_path: str = "", kms_provider: str = "", kms_key_id: str = "")`:
        - If `master_key_path` is set and file exists: load 32 bytes from file
        - If `master_key_path` is set and file doesn't exist: generate 32 random bytes, write to file with `0o600` permissions, use as KEK
        - If neither path nor KMS set: raise `ValueError("No encryption key source configured. Set ALEA_MASTER_KEY_PATH or KMS config.")`
        - Store KEK, create `self.envelope = EnvelopeEncryption(kek)`
      - `def provision_tenant_dek(self, org_slug: str) -> tuple[bytes, bytes]`:
        - Generate DEK: `dek = self.envelope.generate_dek()`
        - Wrap it: `wrapped = self.envelope.wrap_dek(dek)`
        - Return `(dek, wrapped)` -- caller stores `wrapped` in the Organization/tenant config
      - `def get_tenant_dek(self, org_slug: str, wrapped_dek: bytes) -> bytes`:
        - Return `self.envelope.unwrap_dek(wrapped_dek)`
      - `def encrypt_field(self, dek: bytes, plaintext: str) -> bytes`:
        - Return `self.envelope.encrypt_field(dek, plaintext)`
      - `def decrypt_field(self, dek: bytes, ciphertext: bytes) -> str`:
        - Return `self.envelope.decrypt_field(dek, ciphertext)`
    - Module-level: `_key_manager: KeyManager | None = None`
    - `def get_key_manager() -> KeyManager`: lazy-init from settings, cache in `_key_manager`

    **backend/app/db/encrypted_type.py:**
    - Create `class EncryptedString(TypeDecorator)`:
      - `impl = LargeBinary` -- stores encrypted bytes in the database
      - `cache_ok = True`
      - Takes `dek_provider: Callable[[], bytes]` in constructor -- a callable that returns the current tenant's DEK
      - `def process_bind_param(self, value: str | None, dialect) -> bytes | None`:
        - If value is None: return None
        - Get DEK from `dek_provider()`
        - Get `EnvelopeEncryption` instance (create with a dummy KEK -- we only need `encrypt_field` which uses the DEK directly, not the KEK)
        - Actually, simplify: call `encrypt_field_standalone(dek, value)` -- a standalone function that does the AES-256-GCM encryption without needing an EnvelopeEncryption instance
        - Return encrypted bytes
      - `def process_result_value(self, value: bytes | None, dialect) -> str | None`:
        - If value is None: return None
        - Get DEK, decrypt, return string

    **IMPORTANT DESIGN NOTE:** The TypeDecorator approach has a challenge -- it needs the tenant's DEK at query time, which is request-scoped. Two implementation strategies:

    Strategy chosen: **Standalone encryption functions** rather than TypeDecorator. The TypeDecorator pattern doesn't cleanly support request-scoped DEKs (the DEK comes from the tenant context which varies per request). Instead:

    Create standalone functions in `backend/app/db/encrypted_type.py`:
    - `def encrypt_value(dek: bytes, plaintext: str) -> bytes`: AES-256-GCM encrypt using `AESGCM(dek)` with random nonce, return `nonce + ciphertext`
    - `def decrypt_value(dek: bytes, ciphertext: bytes) -> str`: split nonce, decrypt, return string
    - `class EncryptedFieldMixin`: a mixin that provides `_encrypt(self, field_name: str, value: str)` and `_decrypt(self, field_name: str)` instance methods that use the session-scoped DEK

    Also create a **helper context** for use in services:
    - `class EncryptionContext`:
      - `__init__(self, dek: bytes)`
      - `def encrypt(self, plaintext: str) -> bytes`
      - `def decrypt(self, ciphertext: bytes) -> str`
    - `def get_encryption_context(request: Request) -> EncryptionContext`: FastAPI dependency that retrieves the tenant DEK from the request state and returns an EncryptionContext

    This pattern means:
    - Model columns are `LargeBinary` (plain bytes in DB)
    - Services use `EncryptionContext` to encrypt before `INSERT` and decrypt after `SELECT`
    - The DEK is loaded per-request from the tenant's stored wrapped DEK

    Keep the User model's `full_name` as `LargeBinary` (already set in Plan 01). Services will call `encryption_ctx.encrypt("John Doe")` before storing and `encryption_ctx.decrypt(user.full_name)` when reading.
  </action>
