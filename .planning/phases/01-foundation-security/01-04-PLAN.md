    **backend/app/services/consent_service.py:**
    - `class ConsentService`:
      - `__init__(self, session: AsyncSession)`
      - `async def grant_consent(self, user_id: int | None, session_id: str | None, consent_version: str, consent_items: dict[str, bool], ip_address: str | None = None) -> ConsentRecord`:
        - Revoke any existing active consent for this user/session first (set revoked_at)
        - Create new ConsentRecord with granted_at=now, revoked_at=None
        - Return the new record
      - `async def revoke_consent(self, user_id: int | None = None, session_id: str | None = None) -> ConsentRecord | None`:
        - Find active consent (revoked_at IS NULL) for user/session
        - Set `revoked_at = func.now()`
        - Return the revoked record (or None if none found)
      - `async def check_consent(self, user_id: int | None = None, session_id: str | None = None, required_item: str = "ai_processing") -> bool`:
        - Find active consent for user/session
        - Check that `consent_items[required_item]` is True
        - Return True if consent is active and item is granted
      - `async def get_consent_status(self, user_id: int | None = None, session_id: str | None = None) -> ConsentRecord | None`:
        - Return active consent record or None
      - `async def get_active_template(self, org_id: int) -> ConsentTemplate | None`:
        - Return the active ConsentTemplate for the org

    **backend/app/middleware/consent.py:**
    - `class ConsentMiddleware(BaseHTTPMiddleware)`:
      - Define `AI_PROCESSING_PREFIXES = ["/api/v1/analysis", "/api/v1/intake", "/api/v1/research"]` -- endpoints that require consent
      - On request: if path starts with any AI prefix:
        - Get user_id from `request.state` (set by auth dependency) or session_id for kiosk
        - Check consent via ConsentService
        - If no active consent: return 403 with `{"detail": "Consent required before AI processing can begin"}`
        - If consent was revoked: return 403 with `{"detail": "Consent has been revoked. AI processing is paused."}`
      - Skip all other routes (auth, admin, consent itself, health, docs)

    - `POST /grant`: accepts `ConsentGrantRequest`, calls consent_service.grant_consent, returns `ConsentResponse` with 201
    - `POST /revoke`: calls consent_service.revoke_consent, returns `ConsentResponse` (immediate effect per CONTEXT.md)
    - `GET /status`: returns current consent status
    - `GET /template`: returns the active ConsentTemplate for the user's org
    - All endpoints require authentication (get_current_active_user) except: allow kiosk sessions with session_id header

    **backend/app/services/deletion_service.py:**
    - `class DeletionService`:
      - `__init__(self, session: AsyncSession, org: Organization)`
      - `async def preview_deletion(self, user_id: int) -> dict`:
        - Count records that would be deleted per category:
          - `consent_records`: count by user_id
          - `audit_log_entries`: count by actor_id (depends on org policy)
          - `users`: 1 (the user itself)
          - Future: cases, narratives, documents, analysis (return 0 for now -- models don't exist yet)
        - Generate `preview_hash = hashlib.sha256(json.dumps(preview, sort_keys=True).encode()).hexdigest()`
        - Return `{"records_affected": total, "categories": {category: count, ...}, "preview_hash": preview_hash}`
      - `async def confirm_deletion(self, user_id: int, preview_hash: str) -> dict`:
        - Regenerate preview, verify hash matches (prevents stale previews)
        - If hash mismatch: raise 400 "Preview is stale. Please regenerate."
        - Based on `self.org.deletion_policy`:
          - `"full_delete"`: DELETE all user records including audit log entries where actor_id = user_id, then DELETE user
          - `"anonymize"`: UPDATE audit_log SET actor_id=NULL, actor_role=NULL, details=NULL WHERE actor_id=user_id, then DELETE everything else
          - `"time_based"`: same as anonymize but mark for future scheduled deletion
        - Delete ConsentRecords for the user
        - Delete RefreshTokens for the user
        - Delete the User
        - Return `{"message": f"Deletion complete. {total} records removed."}`
