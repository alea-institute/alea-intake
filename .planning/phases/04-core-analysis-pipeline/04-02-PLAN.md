    Create `backend/app/services/analysis/convergence.py` with:

    ```python
    class ConvergenceEvaluator:
        def __init__(
            self,
            weights: ConvergenceWeights | None = None,
            threshold: float = 0.75,
            hysteresis_margin: float = 0.1,
        ):
    ```

    Import ConvergenceSignals and ConvergenceWeights from `app.services.analysis.schemas`. If schemas.py does not exist yet (Plan 01 parallel), define the dataclasses inline with a TODO to switch to shared import.

    `evaluate(signals: ConvergenceSignals) -> tuple[bool, float]` method:
    1. Check hard cap first: if signals.iteration_number >= signals.max_iterations, return (True, 1.0)
    2. Compute per-signal scores:
       - coverage: signals.coverage_pct (direct 0-1)
       - confidence_plateau: 1.0 - min(abs(signals.confidence_delta), 0.1) / 0.1 (smaller delta = higher plateau)
       - iteration_cap: signals.iteration_number / signals.max_iterations (closer to cap = higher)
       - user_fatigue: min(signals.skip_rate * 2, 1.0) (skip rate 0.5+ saturates at 1.0)
       - diminishing_gaps: 1.0 - (signals.new_gaps_count / max(signals.previous_gaps_count, 1)) if previous > 0, else 0.5
    3. Weighted sum: sum(score * weight for each signal)
    4. Apply hysteresis: if previous call was converged, threshold is lowered by hysteresis_margin (convergence is sticky)
    5. Return (combined >= effective_threshold, round(combined, 4))

    Add `from_org_config(cls, config: dict) -> ConvergenceEvaluator` classmethod that reads convergence_weights and convergence_threshold from an AnalysisConfig-style dict.

    Write comprehensive tests in `backend/tests/test_convergence.py` covering all behavior items above. Use pytest parametrize for signal combinations.
