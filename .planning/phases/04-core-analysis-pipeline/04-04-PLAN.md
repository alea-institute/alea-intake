    Create `backend/app/services/analysis/stages/gap_analyze.py`:

    ```python
    class GapAnalyzeStage:
        def __init__(
            self,
            llm_service: LLMService,
            db_session: AsyncSession,
            weak_mapping_threshold: float = 0.5,
        ):
        
        async def execute(
            self,
            run: AnalysisRun,
            iteration: AnalysisIteration,
            claims: list[AnalysisClaim],
            elements: list[ClaimElement],
            mappings: list[FactClaimMapping],
            existing_gaps: list[AnalysisGap],
        ) -> dict:
    ```

    Implementation:
    1. **Unsupported elements:** For each ClaimElement where is_satisfied is False and no FactClaimMapping exists with matching element_id, create gap with type "unsupported_element", priority = parent claim confidence * 100.
    2. **Unexplored claims:** For each AnalysisClaim where is_potential=True and no FactClaimMapping exists with matching claim_id, create gap with type "unexplored_claim", priority = 50.
    3. **Weak mappings:** For each FactClaimMapping where confidence < weak_mapping_threshold, create gap with type "weak_mapping", priority = int((1 - confidence) * 100).
    4. **Procedural requirements:** Call LLM with claims list and ask for procedural gaps (deadlines, filing requirements, statutes of limitations). Parse through GapAnalysisResult. Type = "procedural_requirement".
    5. Filter out gaps that duplicate existing_gaps (same gap_type + claim_id + element_id where status != "addressed").
    6. Compute coverage_pct: count elements with is_satisfied=True / total elements.
    7. Persist all new gaps as AnalysisGap records.
    8. Return dict: {"gaps_count", "coverage_pct", "gap_types" (breakdown by type), "summary"}.

    Update `backend/app/services/analysis/stages/__init__.py` to export GapAnalyzeStage.

    Write tests in `backend/tests/test_gap_analysis.py` with pre-seeded claims, elements, and mappings in DB. Mock LLM for procedural requirement detection.
