    Create `backend/app/services/analysis/__init__.py` (empty, makes it a package).

    Create `backend/app/services/analysis/schemas.py` with Pydantic v2 BaseModel schemas for all LLM structured outputs and stage data flow:

    1. **OrchestratorDecision** -- LLM orchestrator output per D-01:
       - next_stage: Literal["issue_spot", "research", "fact_map", "gap_analyze", "question", "converge"]
       - reasoning: str
       - skip_stages: list[str] = []

    2. **IssueSpotResult** -- issue_spot stage output:
       - claims: list[SpottedClaim]
       - jurisdictions: list[str]
       - summary: str

    3. **SpottedClaim** -- a claim identified during issue-spotting:
       - claim_name: str
       - claim_type: Literal["identified", "discovered"]
       - folio_iri: str | None = None
       - jurisdiction: str | None = None
       - confidence: float
       - rationale: str
       - is_potential: bool = False
       - elements: list[ClaimElementSchema] = []

    4. **ClaimElementSchema** -- element of a claim:
       - element_name: str
       - element_description: str | None = None
       - jurisdiction: str | None = None

    5. **FactMapResult** -- fact_map stage output:
       - mappings: list[FactMappingSchema]
       - unmapped_facts: list[int]  (fact IDs with no mapping)

    6. **FactMappingSchema** -- a single fact-to-claim mapping:
       - fact_id: int
       - claim_name: str
       - element_name: str | None = None
       - llm_confidence: float
       - mapping_rationale: str

    7. **GapAnalysisResult** -- gap_analyze stage output:
       - gaps: list[GapSchema]
       - coverage_pct: float
       - summary: str

    8. **GapSchema** -- a single gap:
       - gap_type: Literal["unsupported_element", "unexplored_claim", "weak_mapping", "procedural_requirement"]
       - claim_name: str | None = None
       - element_name: str | None = None
       - description: str
       - priority: int

    9. **QuestionGenResult** -- question stage output:
       - groups: list[QuestionGroup]
       - total_questions: int

    10. **QuestionGroup** -- topic-grouped questions per D-10:
        - topic: str
        - questions: list[QuestionSchema]

    11. **QuestionSchema** -- a single question:
        - question_text: str
        - rationale: str | None = None
        - priority: int
        - gap_description: str | None = None

    12. **ConvergenceSignals** -- convergence evaluator input per D-13:
        - coverage_pct: float
        - confidence_delta: float
        - iteration_number: int
        - max_iterations: int
        - skip_rate: float
        - avg_response_time_sec: float
        - new_gaps_count: int
        - previous_gaps_count: int

    13. **ConvergenceWeights** -- org-configurable weights per D-13:
        - coverage: float = 0.30
        - confidence_plateau: float = 0.20
        - iteration_cap: float = 0.10
        - user_fatigue: float = 0.15
        - diminishing_gaps: float = 0.25

    14. **ConfidenceWeights** -- org-configurable per D-05:
        - llm_weight: float = 0.4
        - concept_weight: float = 0.3
        - fact_weight: float = 0.3

    15. **AnalysisConfig** -- org analysis config per D-04, D-12, D-13, D-14:
        - auto_trigger_enabled: bool = True
        - auto_trigger_fact_threshold: int = 5
        - max_iterations: int = 10
        - convergence_threshold: float = 0.75
        - convergence_weights: ConvergenceWeights = ConvergenceWeights()
        - confidence_weights: ConfidenceWeights = ConfidenceWeights()
        - question_transparency: bool = True

    - Test ConvergenceWeights defaults sum to 1.0
    - Test ConfidenceWeights defaults sum to 1.0
    - Test AnalysisConfig round-trips to/from JSON (for DB storage)
