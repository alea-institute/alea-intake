    ```python
    class IssueSpotStage:
        def __init__(
            self,
            llm_service: LLMService,
            db_session: AsyncSession,
            folio: FOLIO | None = None,
            embedding_service: EmbeddingService | None = None,

        async def execute(
            self,
            run: AnalysisRun,
            iteration: AnalysisIteration,
            facts: list[ExtractedFact],
        ) -> dict:
    ```

    Implementation:
    1. Build prompt with all extracted facts (assertion_text, fact_type, confidence).
    2. System prompt instructs LLM to identify legal claims, classify as "identified" or "discovered" (D-08), list elements per claim, detect jurisdictions.
    3. Call LLM via `llm_service` using alea-llm-client `.json_async()` pattern. Parse response through `IssueSpotResult` Pydantic schema.
    4. For each claim in result: call `resolve_concepts(claim_name, folio, ...)` to get folio_iri. If folio is None or resolver fails, set folio_iri=None.
    5. Persist each claim as AnalysisClaim record (run_id, claim_name, claim_type, folio_iri, jurisdiction, confidence, rationale, is_potential, iteration_discovered=iteration.iteration_number).
    6. For each claim's elements: persist as ClaimElement records (claim_id, element_name, element_description, jurisdiction).
    7. Return dict with "claims_count", "jurisdictions", "summary", "claims" (list of claim dicts for stage result_json).

    ```python
    class FactMapStage:
        def __init__(
            self,
            llm_service: LLMService,
            db_session: AsyncSession,
            confidence_weights: ConfidenceWeights | None = None,
            folio: FOLIO | None = None,
            embedding_service: EmbeddingService | None = None,
        ):
        
        async def execute(
            self,
            run: AnalysisRun,
            iteration: AnalysisIteration,
            facts: list[ExtractedFact],

        ) -> dict:
    ```

    Implementation:
    1. Build prompt with facts (id, assertion_text, confidence) and claims (id, claim_name, elements) for LLM to generate mappings.
    2. Call LLM via `.json_async()`, parse through `FactMapResult` schema.
    3. For each mapping in result:
       a. Look up the claim by claim_name, get claim_id and element_id.
       b. Get llm_confidence from the LLM output.
       c. Get concept_confidence: call resolve_concepts on the claim's folio_iri context. If folio unavailable, default to 0.5.
       d. Get fact_confidence from ExtractedFact.confidence for the mapped fact_id.
       e. Compute composite: `compute_composite_confidence(llm_conf, concept_conf, fact_conf, self._weights)`.
       f. Create FactClaimMapping record with all fields.
    4. Track unmapped fact IDs (facts not in any mapping).
    5. Update ClaimElement.is_satisfied and satisfaction_confidence based on mappings (element has at least one mapping with confidence > 0.5).
    6. Return dict with "mappings_created", "unmapped_facts", "avg_confidence".
