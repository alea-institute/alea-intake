    **Screening Middleware** (backend/app/services/screening/middleware.py):

    Core function plus priority-based dispatch helpers:

    ```python
    async def screen_message_fast(
        content: str,
        session_id: int,
        db_session: AsyncSession,
        active_protocols: list[tuple[OrgProtocolActivation, ProtocolVersion]] | None = None,
        question_transparency: bool = True,
    ) -> ScreeningResult:
    ```

    Implementation:
    1. If active_protocols not provided, load via ProtocolService(db_session).get_active_protocols(). Cache the TriggerMatcher instance per session to avoid recompiling regex on every message.
    2. Create TriggerMatcher(active_protocols). Call match_fast(content). This is the <50ms fast path.
    3. Group triggered protocols by severity_tier: critical, elevated, advisory.
    4. Build ScreeningResult:
       - has_critical = len(critical_triggers) > 0
       - has_elevated = len(elevated_triggers) > 0
       - has_advisory = len(advisory_triggers) > 0
       - For critical triggers: extract safety_resources from each triggered ProtocolVersion.safety_resources_json and escalation_actions_json["immediate_resources"]. Extract mandatory_questions from questions_json where is_mandatory=True. If question_transparency is True, use text_transparent field; else use text field. Per D-13 and D-14.
       - needs_deep_scan = has_critical (critical triggers should queue a deep exploration run per D-09)
    5. Return ScreeningResult.

    Helper functions:
    - `async def persist_screening_event(db_session, session_id, triggered: TriggeredProtocol, action_taken: str) -> ScreeningEvent`:
      Create and persist a ScreeningEvent record with trigger_details_json capturing matched_terms, trigger_type, etc. action_taken is one of: "immediate_alert", "queued", "folded_to_exploration" per D-10.

    - `def build_safety_alert_message(screening_result: ScreeningResult) -> dict`:
      Build the WebSocket JSON message for critical alerts:
      ```python
      {
          "type": "safety_alert",
          "severity": "critical",
          "resources": screening_result.safety_resources,
          "questions": screening_result.mandatory_questions,
          "message": "We want to make sure you're safe. Here are some resources that may help.",
      }
      ```

    - `async def queue_elevated_screening(db_session, session_id, triggered_protocols) -> None`:
      Persist ScreeningEvent records with action_taken="queued" for elevated-tier triggers. These are surfaced at the next conversation pause (e.g., when the system generates follow-up questions).

    - `async def add_to_exploration_queue(db_session, session_id, triggered_protocols) -> None`:
      Persist ScreeningEvent records with action_taken="folded_to_exploration" for advisory-tier triggers. These inform the next exploration round (Plan 02) about additional areas to explore.

    **TriggerMatcher caching**: The middleware module should maintain a lightweight session-level cache (`_matcher_cache: dict[int, tuple[TriggerMatcher, float]]`) mapping session_id -> (matcher, loaded_at_time). Reload every 5 minutes or on first use for a session. This avoids re-loading protocols from DB and re-compiling regex on every message while still picking up activation changes.

    Updated flow:
    ```python
    async def _handle_text_message(websocket, session_id, user_id, data, engine):
        content = data.get("content", "")
        party_id = data.get("party_id")

        async with engine.connect() as conn:
            conn = await conn.execution_options(schema_translate_map={"tenant": None, "shared": None})
            async with AsyncSession(bind=conn, expire_on_commit=False) as db_session:
                # --- Per-message screening (EXPLORE-04) ---
                from app.services.screening.middleware import (
                    screen_message_fast,
                    build_safety_alert_message,
                    persist_screening_event,
                    queue_elevated_screening,
                    add_to_exploration_queue,
                )

                screening_result = await screen_message_fast(
                    content=content,
                    session_id=session_id,
                    db_session=db_session,
                )

                # Critical: immediate interrupt per D-10
                if screening_result.has_critical:
                    alert_msg = build_safety_alert_message(screening_result)
                    await websocket.send_json(alert_msg)
                    for tp in screening_result.triggered_protocols:
                        if tp.get("severity_tier") == "critical":
                            await persist_screening_event(
                                db_session, session_id, tp, "immediate_alert"
                            )

                # Elevated: queue for next pause per D-10
                if screening_result.has_elevated:
                    await queue_elevated_screening(
                        db_session, session_id,
                        [tp for tp in screening_result.triggered_protocols if tp.get("severity_tier") == "elevated"]
                    )

                # Advisory: fold into exploration per D-10
                if screening_result.has_advisory:
                    await add_to_exploration_queue(
                        db_session, session_id,
                        [tp for tp in screening_result.triggered_protocols if tp.get("severity_tier") == "advisory"]
                    )

                # --- Continue existing message handling ---
                svc = IntakeSessionService(db_session)
                message = await svc.store_message(
                    session_id=session_id,
                    sender_type="consumer",
                    modality="text",
                    content=content,
                    party_id=party_id,
                )
                # ... rest of existing flow unchanged ...
    ```
