    1. Create backend/app/services/analysis/autonomy/approval_queue.py:
       - ApprovalQueue class:
         - __init__: self._pending dict[int, tuple[ApprovalRequestSchema, asyncio.Event, ApprovalAction|None, str]] where str is status ("pending"|"resolved"|"timed_out")
         - create_request(run_id, stage_name, iteration_id, safety_triggered, is_rerun=False, attempt=0, guidance=None) -> ApprovalRequestSchema: creates in-memory entry with asyncio.Event, returns schema
         - wait_for_action(request_id, timeout_seconds, timeout_behavior) -> ApprovalAction: uses asyncio.wait_for with event.wait(); on TimeoutError, returns action based on timeout_behavior (auto_proceed, queue, or pause -- pause re-waits with no timeout)
         - resolve(request_id, action) -> None: atomic status check -- if status is "timed_out", raise ValueError("Request already timed out"). Otherwise set action, mark "resolved", call event.set()
         - get_pending() -> list[ApprovalRequestSchema]: return all pending requests
         - Race condition protection (Pitfall 2): resolve checks status atomically before setting event

           a. Check config: needs_approval = safety_triggered OR checkpoint == CHECKPOINT (D-02 safety override)
