Build the REST API layer for autonomy: professional approval endpoints (list pending, approve, reject, edit, mode-switch), admin config CRUD, autonomy audit trail, WebSocket event broadcasting for consumer status, and wire everything into main.py.

       - Global ApprovalQueue instance: module-scoped singleton (same instance the interceptor uses)
