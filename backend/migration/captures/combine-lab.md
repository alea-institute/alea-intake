# The average-combine oddity — characterization and remedies

_Generated by `migration/combine_lab.py`. Study only: nothing under `app/` is changed._

## 1. The algebra

At the production operating point (penalty **0.7**, threshold **0.5**), for a candidate the label stage scores `L`:

| | score |
|---|---|
| not retrieved by the embedding stage | `penalty × L` |
| retrieved at cosine `e` | `(e + L) / 2` — the two stages carry equal weight (0.3 / 0.3) |

* **Rank inversion** whenever `e < 0.40 × L`.
* **Accept inversion** — a candidate that would have been RETURNED unretrieved is DROPPED once retrieved — whenever `L ≥ 0.7143 and e < 1.00 − L`.

The widest accept-inversion band sits at `L = 0.7143` (the solo bar): every embedding cosine below **0.2857** turns an accepted concept into a rejected one. That is not a corner: cosines in the low tenths are exactly what a broad-recall retrieval stage produces for a marginal candidate.

## 3. End to end (through the real `resolve_concepts`)

One concept, one query (`"Retaliation"` → *Retaliation Claim*, label score 0.736), four embedding stages that differ only in how strongly they retrieve it:

| case | embedding | concepts resolved | confidence |
|---|---|---|---|
| embedding stage returns nothing | None | 1 | 0.5152 |
| embedding stage returns it at cosine 0.10 | 0.1 | 0 | None |
| embedding stage returns it at cosine 0.20 | 0.2 | 0 | None |
| embedding stage returns it at cosine 0.30 | 0.3 | 1 | 0.518 |

A retrieval stage that finds the right concept — weakly — makes the system return **less** than a retrieval stage that finds nothing at all.

## 4. Remedies

| rule | evidence-monotone | worst drop | stage-monotone | bounded | label-only exact | both-stages exact |
|---|---|---|---|---|---|---|
| `current` | **no** | 0.2 | yes | yes | 0.693 | 0.99 |
| `floor` | yes | 0.0 | yes | yes | 0.693 | 0.99 |
| `presence` | yes | 0.0 | yes | yes | 0.297 | 0.594 |
| `coverage` | **no** | 0.3455 | yes | yes | 0.7713 | 0.8584 |

*evidence-monotone* = adding a stage never lowers the score. It is the property the status quo lacks, and the only one that matters for this defect; the others are there to show what a remedy costs elsewhere.
